# InterfaceWorks

## What is it?
InterfaceWorks is a simple UI State controller for Roblox.

## Docs
All documentation is available [here](https://sratique.github.io/InterfaceWorks-Docs/).

## Tooling used
To build a binary Yourself, You will need:
- [Rojo](https://rojo.space/)
- [darklua](https://darklua.com/)

All the build properties files are in the repo.

## Versions
If you can't find a specific version, then it might be available only through wally.
Until 1.0.0 the only supported version is the newest one.

## Disclaimer
This library is still under heavy development. APIs might break, get deprecated or removed altogether.
The documentation page is also not finished and might not reflect the actual state of the library immediately after every update.
